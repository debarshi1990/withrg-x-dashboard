<product_requirements>
The product is the WithRG X Dashboard, a mobile and web application for team-based Twitter (X) account management, similar to Facebook Business Suite, for a political volunteer network named *WithRG*.
**Purpose:** Enable a Super Admin to manage multiple Twitter (X) handles across Indian states without sharing passwords, delegating specific access (posting, retweeting, analytics) to team members.
**User Roles:**
1.  **Super Admin:** Full control of all handles, add/remove handles, assign/revoke user access, view all analytics, rank handle performance.
2.  **Admin:** View all analytics/activity logs, assign/revoke Posters for assigned handles, cannot add/remove handles.
3.  **Poster:** Post, retweet, view insights only for assigned handles.
**Authentication:** Google login or email-password, Role-based Access Control (RBAC), OAuth2-based Twitter handle connection.
**Twitter (X) Integration:** Post text+image tweets, retweet, view tweet insights (likes, retweets, impressions), view recent tweets, schedule posts (optional).
**Dashboard:** List handles, assigned users, weekly/monthly engagement stats, handle ranking, activity feed, filters.
**Admin Panel:** Add/remove Twitter handles via OAuth, view authorization status, assign users, revoke access, view audit logs.
**UI Screens:** Login/Sign up, Handle selection, Compose & post tweet, Retweet section, Tweet insights, Dashboard, Admin Panel, Activity logs, Profile/Settings.
**Notes:** No password access to Twitter handles (authorized tokens only), scalable for 30+ handles/team members, secure RBAC, clear insights per handle.
</product_requirements>
